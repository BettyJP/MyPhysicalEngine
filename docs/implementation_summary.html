実装概要

このプロジェクトは、C++開発環境の動作確認を行うためのサンプル実装です。

プロジェクト構造

  • src/: ソースコードを格納するディレクトリ。
  • build/: ビルド生成ファイルが格納されるディレクトリ。
  • CMakeLists.txt: プロジェクトのビルド構成を定義するCMakeファイル。

主要な実装内容

1. サンプルソースコード (src/hello.cpp)

C++の標準ライブラリ (<iostream>) を使用して、コンソールにメッセージを表示する基本的なプログラムです。

  • 機能: "Hello, C++ development environment is working!" という文字列を出力。
  • 規格: C++17 標準。

2. ビルドシステム (CMakeLists.txt)

CMakeを使用して、クロスプラットフォームに対応したビルドシステムを構築しています。

  • 設定内容:
  • C++標準: C++17
  • ターゲット: hello (executable)
  • ソースファイル: src/hello.cpp

ビルドおよび実行手順

ビルドおよび実行の手順は以下の通りです。

# ビルドディレクトリの作成と設定
cmake -S . -B build

# コンパイルの実行
cmake --build build

# 実行（Windowsの場合）
.\\build\\Debug\\hello.exe
