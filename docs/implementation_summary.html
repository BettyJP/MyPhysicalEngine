実装概要

このプロジェクトは、PBD (Position Based Dynamics) をベースとした物理エンジンを開発するためのサンプル実装です。

プロジェクト構造

  • src/: ソースコードを格納するディレクトリ（Math, Physics, Main）。
  • docs/: プロジェクトのドキュメントを格納するディレクトリ。
  • build/: ビルド生成ファイルが格納されるディレクトリ。
  • CMakeLists.txt: プロジェクトのビルド構成を定義するCMakeファイル。

主要な実装内容

1. 数学ライブラリ (src/PhysicsEngine/Math/Vector3.hpp)

3次元空間でのベクトル演算を提供します。

  • 機能: 加算、減算、スカラー乗算、ドット積、長さの計算。
  • 規格: C++17 標準。

2. 物理オブジェクト (src/Physics/PointMass.hpp/cpp)

質量を持つ点（Point Mass）の物理的属性を管理します。

  • 機能: 位置 (Position)、速度 (Velocity)、質量 (Mass) の保持と更新。

3. シミュレーション世界 (src/Physics/PhysicsWorld.hpp/cpp)

複数の PointMass を管理し、重力等の外力を適用してシミュレーションを進行させます。

  • 機能: 重力ベクトルによる逐次的な時間ステップ (Time Step) 演算。

4. 視覚化システム (src/main.cpp)

OpenGL を使用して、物理シミュレーションの結果をリアルタイムで描画します。

  • 機能: GLFW/GLAD によるウィンドウ管理、シェーダーによる描画、簡易的な地面衝突判定の視覚化。

ビルドおよび実行手順

ビルドおよび実行の手順は以下の通りです。

# ビルドディレクトリの作成と設定
cmake -S . -B build

# コンパイルの実行
cmake --build build

# 実行（Windowsの場合）
.\\build\\Debug\\PhysicsSim.exe
