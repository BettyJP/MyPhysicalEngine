1. プロジェクトの目的

MyPhysicalEngine は、C++17 および Modern OpenGL (3.3 Core Profile) を用いて構築された高性能かつ視覚的に高品質な 3D 物理シミュレーションエンジンです。
質点（PointMass）・球体（Sphere）の運動計算、重力落下、物体間・環境境界との衝突判定および反発インパルス計算をリアルタイムでシミュレーションし、Blinn-Phong ライティングを用いた 3D グラフィックス描画およびリアルタイム最高画質 (H.264 Lossless / Apple ProRes) での動画録画機能を提供します。

3. 主要コンポーネントの役割

  • Physics Engine Module (PhysicsEngine::Physics)

    PhysicsWorld: シミュレーション全体の統合クラス。Symplectic Euler 積分、球体同士の衝突検知・位置補正・反発インパルス応答、コンテナ境界との衝突計算を管理。
    PointMass: 質量、半径、位置、速度、反発係数、カラーおよび力の蓄積器を持つ質点・球体物理オブジェクト。

  • Math Module (PhysicsEngine::Math)

    Vector3: 3次元ベクトルの基本データ構造。加減乗除、ドット積、クロス積、正規化、自乗長さを提供。

  • Geometry Module (PhysicsEngine::Geometry)

    SphereMesh: UV Sphere（緯度・経度分割）の 3D メッシュ（頂点位置・法線・EBO）を動的生成し、VAO/VBO/EBO をカプセル化して描画。

  • Utils Module (PhysicsEngine::Utils)

    MP4Recorder: OpenGL のフレームバッファ (glReadPixels) をキャプチャし、FFmpeg の標準入力パイプへストリーミングして無劣化動画 (MP4/MOV) にエンコード。
